How a build runs, from spec to support

  1. Specify

    A tight build spec: what the site has to do, the stack, integrations, hosting, CMS and deploy pipeline. Agreed before anyone writes code.

  2. Scaffold

    Repository, CI, staging and CMS go up first, so every page from then on deploys automatically and you can review it.

  3. Build

    Pages, components and templates built against the design system and tested on real devices, with performance and accessibility checked every sprint.

  4. Launch

    DNS cutover, redirects, analytics, sitemap and monitoring, in a controlled go-live.

  5. Support

    An optional retainer for ongoing work, or a clean handover to your team, with documentation written for someone who wasn't in the room.

Web development questions we hear a lot

Typical prices, from DIY builders to agencies: how much a website costs in the UK. Need an existing site made accessible? See our accessibility audits and fixes.
What tech stack do you build websites on?

We default to static-first builds with Astro, Tailwind CSS for styling, MDX for content, and a headless CMS (Sanity, Contentful or Storyblok, depending on fit) when the client needs to edit. For applications we use React, Next.js or Vue where the complexity justifies it, but we start with the lightest architecture that solves the problem.

How much does a custom website build cost?

Custom web development at OakFox typically ranges from £2,500 for a static marketing site to £20,000 or more for a multi-section, CMS-driven site with integrations. Every quote is worked out case by case, and we send a detailed written proposal after a free first call.

What is "green web hosting" and why does it matter?

Green web hosting runs on verified renewable power (solar, wind or hydro) rather than fossil-fuel-backed grid power. Websites account for a meaningful share of global digital emissions, so choosing a host is one of the highest-leverage sustainability decisions a business makes. We deploy by default to providers on The Green Web Foundation's verified list.

Do you work with Shopify, WordPress, or other CMS platforms?

Yes, where they fit. Shopify for e-commerce when its feature set matches, and Shopify Hydrogen where a custom frontend is justified. WordPress only when the client has an existing setup we shouldn't break. For most marketing sites we prefer a headless CMS: faster, more secure, easier to maintain, and far fewer plugin conflicts.

Will my website be fast and pass Core Web Vitals?

Yes. Every site we build targets a Lighthouse performance score of 95 or more and green Core Web Vitals from launch. Static rendering, optimised images, minimal JavaScript and edge hosting give pages that load in well under a second on 4G. We check this every sprint, not just at the end.

Do you offer ongoing website support and maintenance?

Yes. After launch we offer monthly retainers covering security updates, content edits, performance monitoring and small features, scoped to the hours you actually need rather than a fixed package. Or we hand over cleanly to your in-house team, with documentation written for someone who wasn't in the room.
